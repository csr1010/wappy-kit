## Tests introduced (`*.m9.test.ts`, generated-project tests in e2e)
- Interview machine: table tests over all paths; invalid combos blocked; back/skip behavior.
- **Combo matrix** (pairwise over model × framework × memory × router × tools × whatsapp): each generates a project that **typechecks, boots, and answers Spine A** with mocks.
- **Resume-at-every-boundary:** run the CLI as a child process, `SIGINT`/`SIGKILL` after step k for every k; rerun → completes, no duplicated side effects, final tree == uninterrupted run.
- `reset` (all / per plugin) removes exactly the generated files; `doctor` catches missing/invalid key, bad creds, unreachable API, hand-edited file (drift).
- Secrets: canary key typed in the interview appears nowhere in generated files/state (grep test).
- Broken OpenAPI URL → interview fails at that step with a clear message, state records `failed`, resume works after fixing.
