## Tasks
- [x] **T3.1** Signature verification: HMAC-SHA256 over the **raw body bytes** with app secret, constant-time compare, reject missing/malformed header. (Framework must expose raw body — parsing JSON first breaks the signature.) *(commit 5489145)*
- [x] **T3.2** GET webhook verification handshake (`hub.mode/verify_token/challenge`). *(commit bebe367)*
- [x] **T3.3** Parser → `InboundMessage` for: text, interactive button reply, interactive list reply, image/document/audio/video/voice, location, reaction, unsupported/unknown types (never throw). Batched entries/changes/messages arrays handled. *(commit 2e633e5; unrecognized interactive subtypes — e.g. Flow replies — fixed to flag unsupported too in e916f20. No `kind` discriminant field was added to core; unsupported/unrecognized types are flagged via a `[unsupported WhatsApp message type: ...]` placeholder in `text` instead — see docs/CONTRACTS.md.)*
- [x] **T3.4** Status webhooks parsed into `StatusEvent` (sent/delivered/read/failed + error code) and routed to a handler (consumed by M4). *(commit 2e633e5, wired to `onStatus` in ce77c6f; deduped + made retry-safe in c2bc22e/e916f20)*
- [x] **T3.5** Dedupe on `message.id`: pluggable `SeenStore` (memory + LibSQL), TTL, atomic check-and-set (concurrent duplicate deliveries → one winner). *(commit feb526b; memory impl only — a persistent LibSQL impl is deferred until a real libsql dependency exists in the workspace, M5/M10; bounded memory via amortized sweep in 4ec5a04/c2bc22e)*
- [x] **T3.6** 24h session-window tracker: derived from last inbound timestamp per contact; `windowOpen(contactId, now)`. *(commit 4ce0f41)*
- [x] **T3.7** Inbound media: download via Graph API with size + mime allow-list validation; clear typed errors; streaming to a size cap (never buffer unbounded). *(commit 96a2709, non-streaming fallback path hardened in c2bc22e)*
- [x] **T3.8** Implement `MessageChannel.receive` and pass `runChannelConformance`. *(commit ce77c6f; `send()` is intentionally text-only — SmartMessage rich rendering + fallback is M4)*
- [x] **T3.9** Record real-shaped payloads into `fixtures/whatsapp/inbound/*.json` (append-only; synthesized from Meta's documented shapes — flag any not verified against live traffic). *(commit 2e633e5)*

## Tests introduced (`*.m3.test.ts`)
- Signature: valid, forged, tampered body, missing header, wrong secret, timing-safe path exercised, unicode/large body.
- Parser: every fixture → expected `InboundMessage`; fuzz/property test: arbitrary JSON never throws.
- Dedupe: same id ×50 concurrent → exactly one processed; after TTL → processed again.
- Window: 23h59m open, 24h01m closed (fake clock).
- Media: oversize aborts early, bad mime rejected, download error mapped.
- Status-only and empty payloads → 200 OK, no message emitted.
