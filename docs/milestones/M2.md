## Tests introduced (`*.m2.test.ts`)
- Crash mid-write (kill between temp write and rename) → old state intact.
- Concurrent runs: spawn 5 child processes racing `withLock`; exactly one wins at a time; stale lock recovered after simulated `kill -9`.
- Resume: fail step k of n, rerun → steps < k not re-executed (spy counters).
- Corrupt JSON / wrong types / truncated file → `StateCorruptError`, never a crash or silent reset.
- Env: filled values never appear in serialized state (grep test with a canary secret).
- Migration loop over **every** `fixtures/state/v*.json`; future-version fixture refused.
- Drift: edit generated file → detected; unchanged → clean.
