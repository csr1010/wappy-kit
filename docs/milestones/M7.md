## Tests introduced (`*.m7.test.ts`)
- Golden snapshots of generated tools per fixture.
- Broken spec → clear install-time error with location; partially bad spec → good ops kept, bad ones in `SkipReport`.
- 800-op spec → parse < budget (perf assertion, generous), curated to ≤ N; selector (M6) finds the right tool.
- Executor against `mockOpenApiServer`: path/query/header/body mapping, auth injection, 4xx/5xx/timeout/invalid JSON/huge body → normalized results.
- Security: `../` and encoded slashes in path params, `__proto__` keys in body, SSRF matrix (127.0.0.1, 169.254.169.254, `[::1]`, DNS-rebind style hostname stub, redirect to private IP).
- Policy: default read-only excludes POST/PUT/PATCH/DELETE; `confirmBefore` surfaced on write tools.
