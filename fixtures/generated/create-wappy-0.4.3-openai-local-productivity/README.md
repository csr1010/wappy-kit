# wappy-bot

A WhatsApp agent generated by `npm create @wappy_ai/agent`.

## 1. Add your credentials

```sh
cp .env.sample .env   # then fill in every key that has no default
```

`.env` is git-ignored — secrets never leave your machine. Where to get each key:

- `OPENAI_API_KEY` — OpenAI API key — create one at https://platform.openai.com/api-keys
- `WHATSAPP_PHONE_NUMBER_ID` — Meta developer app > WhatsApp > API Setup > Phone number ID.
- `WHATSAPP_ACCESS_TOKEN` — Meta developer app > WhatsApp > API Setup > access token (the temporary one expires in 24h; create a System User token for production).
- `WHATSAPP_VERIFY_TOKEN` — Any string you choose (e.g. a random password). Enter the same value in Meta's webhook config.
- `WHATSAPP_APP_SECRET` — Meta developer app > App settings > Basic > App secret. Used to verify webhook signatures, so forged requests are rejected.
- `MEMORY_DB_URL` (optional) — LibSQL URL for conversation memory. Default: a local file at .wappy/memory.db (nothing to set).
- `SESSION_PROFILE_DB_URL` (optional) — LibSQL URL for the session profile (facts + current thread state). Default: a local file at .wappy/session-profile.db (nothing to set).
- `KNOWLEDGE_DB_URL` (optional) — LibSQL URL for local knowledge/RAG storage (only used when the memory backend is local). Default: a local file at .wappy/knowledge.db (nothing to set).
- `GOOGLE_CLIENT_ID` (optional) — Your own Google Cloud OAuth Client ID — see GOOGLE_SETUP.md.
- `GOOGLE_CLIENT_SECRET` (optional) — Your own Google Cloud OAuth Client secret — see GOOGLE_SETUP.md.

## 2. Connect WhatsApp

See [`WHATSAPP_SETUP.md`](./WHATSAPP_SETUP.md) for the full walkthrough: creating the Meta app,
getting a public webhook URL from your own machine, and wiring it into Meta's webhook config.

## 3. What was generated

- **Model:** openai
- **Memory:** local SQLite file (`.wappy/memory.db`), plus a session profile (`.wappy/session-profile.db`) — facts and where the conversation currently stands, TTL-bound
- **Memory backend:** Local (LibSQL) — retrieved knowledge is stored and searched entirely on your own machine (BM25 keyword matching), no account or extra setup needed.
- **Productivity agent:** on — reads (never writes) your own Gmail/Calendar for any question phrased in normal language, no saved tasks and no fixed list of things it can answer, no cron and no WhatsApp Message Template ever needed. Replies honestly that it's not connected until you connect Google (see [`GOOGLE_SETUP.md`](./GOOGLE_SETUP.md), then tap "Connect Google" on the local connect page).

No tools/connectors are wired by default — see `index.ts`'s comment above `createAgent` for how to add one.

Once WHATSAPP_SETUP.md's steps are done, `npm run dev` (this project's `wappy dev`) starts the
webhook server and the local Google-connect page (its URL prints alongside the webhook URL).
Run `wappy status` any time to see what's done vs. pending, and `wappy doctor` to
validate your env + connectivity.
